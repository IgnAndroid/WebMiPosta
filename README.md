# WebMiPosta# 🏥 WebMiPosta

Sistema web de gestión de citas médicas desarrollado con Django.  Permite a pacientes agendar citas médicas, a médicos gestionar su agenda y consultas, y a administradores controlar todo el sistema.

## 📋 Características

### 👤 **Para Pacientes**
- ✅ Registro e inicio de sesión seguro
- 📅 Agendar citas con médicos por especialidad
- 🔔 Recibir notificaciones de citas
- 📊 Ver historial de citas
- ✏️ Cancelar o reprogramar citas

### 👨‍⚕️ **Para Médicos**
- 📋 Gestionar agenda de citas
- 👥 Ver lista de pacientes
- ✍️ Agregar notas y diagnósticos
- ⏰ Configurar horarios de atención
- 📈 Estadísticas de consultas
